# Recursos compartilhados

Esta pasta reúne elementos gráficos e arquivos reutilizáveis que podem ser empregados em diferentes projetos do repositório.

## Templates

Modelos-base para a produção de documentos, legendas, linhas, operadores e outros elementos gráficos. Os arquivos de template também incluem modelos de caixinhas e suas exportações.

## Ícones

Arquivos gráficos reutilizáveis, disponibilizados em diferentes formatos. Atualmente, esta pasta contém o ícone de ônibus em AI, PDF, PNG e SVG.
